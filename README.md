# My Node TypeScript App

This project is a Node.js application built with TypeScript. It serves as a template for creating scalable and maintainable applications using modern JavaScript features and best practices.

## Features

- TypeScript for type safety and modern JavaScript features
- Express.js for building web applications and APIs
- Jest for testing
- ESLint for code linting
- Prettier for code formatting
- GitHub Actions for CI/CD

## Getting Started

### Prerequisites

- Node.js (version 14 or higher)
- npm (Node package manager)

### Installation

1. Clone the repository:
   ```
   git clone https://github.com/yourusername/my-node-ts-app.git
   ```

2. Navigate to the project directory:
   ```
   cd my-node-ts-app
   ```

3. Install the dependencies:
   ```
   npm install
   ```

### Running the Application

To start the application in development mode, run:
```
npm run start
```

### Running Tests

To run the tests, use:
```
npm run test
```

### Linting

To lint the code, execute:
```
npm run lint
```

### Formatting

To format the code, run:
```
npm run format
```

## CI/CD

This project includes GitHub Actions workflows for continuous integration and release management. The workflows are defined in the `.github/workflows` directory.
